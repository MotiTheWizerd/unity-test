# Sounds

Each folder holding recordings is a sound, keyed by its path in lowercase (`Footsteps/Walk` → `footsteps/walk`);
its optional `<Name>.json` says how it plays. *Forge → Sounds → Build Sounds* builds them (see ARCHITECTURE.md, Sound).

```
Footsteps/           a step of each gait: Walk Run Sneak, and of each surface: Wet (Footsteps/<Surface>[/<Gait>])
Foley/               the body moving: Jump, and in a voice (<Sound><Voice>): JumpFemale, a woman's breath as she jumps
Combat/              a combat move's moment, by its animation: SwordSlash (the swish), BowShot (the draw's
                     creak), BowRelease (the string's snap)
_Built/              made by the builder: the takes split out of the recordings, and the cues; don't put sounds here
```
